# P001 CHANGELOG

이 작품의 **산출물 버전**을 기록합니다(최신이 위).

- 버전 이름: `대본 v1`, `샷리스트 v2`, `편집본 v1`, `최종본`, `YouTube 공개` 등
- 버전은 원본 파일 이름과 1:1로 맞춥니다: `편집본 v2` = `P001_edit_v2.mp4`
- "왜"는 한 줄만 씁니다. 길어지면 결정 문서(`studio/decisions/`)를 만들고 링크합니다.
- 세부 과정은 `03-production/generation-log.md`에 씁니다.

형식:
```
## 편집본 v2 — 2026-10-20
- 무엇: S03 샷을 v4로 교체, 전체 길이 1:42 → 1:38
- 왜: S03 v3에서 손가락이 깨져 보임
- 이슈: #12
```
