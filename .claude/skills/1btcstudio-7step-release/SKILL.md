# /1btcstudio-7step-release — 공개 준비

준호가 문장과 썸네일 구상만 쓴다. 영상을 생성하지 않고, YouTube에 올리지 않는다. 서브에이전트를 부르지 않고, 이 단계만 끝내고 멈춘다. 대표에게 제목을 고르라고 묻지 않는다. 추천안을 채택해 적고, 공개는 대표 승인 항목으로만 남긴다.

## 시작 조건
`04-post/edit-notes.md`가 있어야 한다. 없으면 멈추고 `/1btcstudio-6step-post`를 다음으로 적는다. 가편집 파일이 없어도 문장 작업은 한다.

## 읽기
대본, 편집 노트, `studio/agents/post.md`의 제목·자막 규칙.

## 결과
`05-distribution/youtube.md`에 새 섹션을 위에 추가한다.

- 제목 후보 3개와 추천 1개. 100자 이내. 핵심은 앞 40자. 낚시성 과장 금지.
- 썸네일 구상 3개. 이미지 생성은 하지 않는다.
- 설명 2~3줄, "이 영상은 AI 생성 도구로 제작되었습니다", 사용 툴, 태그.
- 공개 전 체크: 합성 콘텐츠 표시, 음악·음성 라이선스, 비공개로 확인한 뒤 공개. 실행은 대표가 한다.

유나는 추천 제목만 잠근다. 제목 의견을 새로 내지 않는다. 작품 `README.md`의 5. 배포는 🔄로 둔다. 공개 전이므로 ✅로 바꾸지 않는다. 커밋하지 않는다.
