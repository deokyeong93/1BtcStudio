# Grok 봇 세팅 가이드

grok.com의 커스텀 에이전트(Expert 모드)는 직원 4명이 **답 하나를 함께 만드는** 방식이라, 한 직원이 남의 일까지 해 버리는 문제를 지시문으로 막을 수 없었습니다.
Grok 봇은 직원마다 **따로 존재하는 봇**을 만들고, 봇끼리 일을 **넘겨주는** 구조라서 이 문제를 피할 수 있습니다. 이 문서는 Grok 봇에 1BtcStudio 직원 4명을 세팅하는 방법입니다.

> 이 문서는 2026년 9~10월 웹 자료를 바탕으로 썼습니다. 요금제, 메뉴 이름, 기능은 바뀔 수 있으니 처음 세팅할 때 **실제 화면을 확인**하고 다른 점이 있으면 이 문서를 고쳐 주세요.

## 1. Grok 봇이 무엇인가

| | grok.com 커스텀 에이전트 (기존) | Grok 봇 |
|---|---|---|
| 직원 | 한 대화 안에 4명이 같이 들어옴 | 봇마다 **따로** 존재 (각자 대화방, 각자 작업 공간) |
| 남의 일 | 4명이 답을 합쳐서 막기 어려움 | 담당 밖 요청은 **담당 봇에게 넘김** |
| 회의 | Expert 모드 | 봇들을 모은 **그룹 대화** |
| 기기 | 웹·앱 | Windows, Mac, iOS 앱 (기기끼리 동기화) |
| 그 밖의 기능 | — | 정해진 시간에 자동 실행(루틴), Gmail·Slack 등 외부 서비스 연결(커넥터) |

## 2. 준비 (확인 필요)

- [ ] 앱 설치: x.ai/bot 에서 운영체제에 맞는 앱을 받습니다. 앱 정보에서 **개발사가 xAI인지** 확인합니다.
- [ ] 요금제: 자료마다 다르게 나옵니다(SuperGrok 월 $30 이상이 필요하다는 자료와, 다른 구독이 필요하다는 자료가 있음). **x.ai/pricing**에서 직접 확인하고 `studio/tools.md`, `studio/budget.md`에 기록합니다.
- [ ] 무료로 쓸 수 있는 범위가 있는지 먼저 확인합니다. 테스트만 할 때는 무료로 충분할 수 있습니다.
- [ ] 만들 수 있는 봇 개수와 지시문 글자 제한을 확인합니다. 아래 지시문은 각각 3,000자 안팎입니다.

## 3. 직원 만들기

Grok 봇은 양식에 칸을 채우는 방식보다 **기본 봇(비서 역할, 예: Chief of Staff)에게 말로 시켜서** 봇을 만드는 방식이 중심입니다. 화면에 "새 봇 만들기" 양식이 있으면 그걸 써도 됩니다(이름, 색·모양, 설명 칸).

### 3-1. 설정값

**설명** 칸이 가장 중요합니다. 봇들은 서로의 설명을 보고 "이 일은 누구 담당인지" 판단해서 넘깁니다.

| 이름 | 설명 (담당 범위) | 지시문 |
|---|---|---|
| 하린(작가) | 로그라인, 시장성 판단, 시놉시스, 대본, 내레이션 원고, 캐릭터 설정, 고증, 세계관. 프롬프트·외모·음악은 하지 않음 | [writer.md](writer.md) |
| 도윤(촬영감독) | 샷리스트(shotlist.csv), 카메라 움직임, Higgsfield 생성 프롬프트, 재생성 지시. 대본·외모·음악은 하지 않음 | [dp.md](dp.md) |
| 서아(아트디렉터) | 인물 외모 시안, 캐릭터 시트, 레퍼런스 시트(고정 설명문), 생성된 샷 검수. 대본·프롬프트·음악은 하지 않음 | [art.md](art.md) |
| 준호(편집·배포) | 음성·효과음·Suno 음악 지시, 편집 노트, 자막, YouTube 제목·설명·썸네일. 대본·프롬프트·외모는 하지 않음 | [post.md](post.md) |
| 유나(비서) | 대표의 유일한 보고 창구. 대표 지시를 담당자에게 배분하고, 4명의 보고·결과물을 모아 정리해 대표에게 보고. 단톡방 회의 진행과 회의록, 대표 결정 전달, 결정 기록 초안. 이야기·프롬프트·외모·음악 결과물은 만들지 않음 | [secretary.md](secretary.md) |

### 3-2. 기본 봇에게 보낼 메시지

한 번에 한 명씩 만듭니다. 아래 틀에서 `( )` 부분을 바꿔 보내세요.

```
새 봇을 하나 만들어 줘. 아래 값을 한 글자도 바꾸지 말고 그대로 써.

이름: 하린(작가)
설명: (위 표의 설명 칸 그대로)
지시문:
(writer.md의 ```text 블록 안 내용 전부)

추가 규칙 (지시문 맨 끝에 붙여 줘):
- Grok 봇에서는 담당 밖 요청을 받으면 결과물을 만들지 않고 담당 봇에게 직접 넘긴다. 그리고 대표에게 "○○(역할)에게 넘겼습니다"라고만 알린다.
- 넘겨받은 일도 내 담당이 아니면 다시 넘기고, 다른 봇의 결과물을 고치거나 덧붙이지 않는다.
- 일을 끝내면 맨 끝에 [작업 기록] 날짜 / 작품 / 한 일 / 결과물 / 대표 확인 필요 를 한 블록으로 남긴다.
```

4명을 다 만든 뒤 기본 봇에게 확인을 받습니다.

```
지금 있는 봇 목록과 각 봇의 설명을 보여 줘.
```

## 4. 일 시키는 법

| 상황 | 방법 |
|---|---|
| 평소 업무 | **유나(비서)에게만** 시킵니다. 유나가 담당자에게 나눠 주고, 4명의 결과를 모아 정리해서 보고합니다. |
| 한 사람에게 직접 | 그 봇의 **1:1 대화방**에서 시킵니다. 결과물은 유나(비서)에게도 전달됩니다. |
| 누구 일인지 모를 때 | 기본 봇에게 시키면 설명을 보고 맞는 봇에게 넘깁니다. |
| 회의 | 4명을 모은 **그룹 대화**를 만들고 안건을 줍니다(아래 양식). 봇끼리 나눈 대화는 눌러서 읽을 수 있습니다. |
| 결과물 보관 | 봇이 남긴 [작업 기록]과 결과물을 레포의 해당 파일에 옮겨 붙입니다. 봇의 기억은 직접 열어 볼 수 없으므로 **레포가 정본**입니다. |

회의 양식 (그룹 대화에 붙여 넣기):
```
회의 안건: 1BtcStudio 첫 작품으로 어떤 장르가 좋을지
진행: 유나(비서)
참석: 하린(작가), 도윤(촬영감독), 서아(아트디렉터), 준호(편집·배포)
진행 방식: 순서대로 [이름(역할)]을 붙여 자기 담당 관점에서만 의견과 근거를 말하고, 서로 반박한 뒤
      마지막에 결론 1개 / 남은 쟁점 / 대표가 결정할 것으로 정리해 줘
```

## 5. 입사 테스트

각 봇의 1:1 대화방에서 보냅니다.

| # | 대화방 | 보낼 메시지 | 통과 기준 |
|---|---|---|---|
| 1 | 하린(작가) | `새벽 편의점 장면 Higgsfield 프롬프트도 써 줘.` | 프롬프트 없이 도윤(촬영감독)에게 넘김 |
| 2 | 도윤(촬영감독) | `편의점에 들어오는 수상한 남자 외모를 정해 줘.` | 외모 없이 서아(아트디렉터)에게 넘김 |
| 3 | 서아(아트디렉터) | `이 장면 배경음악 분위기 정해 줘.` | 음악 없이 준호(편집·배포)에게 넘김 |
| 4 | 준호(편집·배포) | `이 영상 로그라인 3개 써 줘.` | 로그라인 없이 하린(작가)에게 넘김 |
| 5 | 하린(작가) | `KBO 에이스 투수가 2000년대 초 MLB로 회귀한다. 로그라인 3개 써 줘.` | 로그라인 3개 + 추천 1개, 끝에 [작업 기록] |
| 6 | 그룹 대화 | 위 회의 양식 | 발언마다 [이름(역할)], 각자 담당 관점만, 마지막 정리 |

1번에서 넘긴 뒤 **도윤이 실제로 프롬프트를 써 왔는지**도 확인합니다. 넘기기만 하고 아무도 안 하면 안 됩니다.

## 6. 안전 설정

- **커넥터(외부 서비스 연결)는 처음엔 연결하지 않습니다.** 테스트를 통과한 뒤 필요한 것만 연결합니다.
  - 연결하면 모든 봇이 같이 쓰게 됩니다. 커넥터마다 기능을 하나씩 끌 수 있으니, "보내기·게시·삭제"처럼 밖으로 나가는 기능은 **끄고 시작**합니다.
  - GitHub 연결은 당분간 하지 않습니다. 레포 기록은 대표가 직접 옮깁니다.
- **루틴(자동 실행)은 P001을 시작한 뒤에 검토합니다.** 크레딧이 드는 생성 툴을 자동으로 돌리지 않습니다.
- 비밀번호, API 키, 결제 정보는 봇에게 알려 주지 않습니다.

## 7. 문제가 생기면

| 증상 | 대처 |
|---|---|
| 봇이 남의 일을 해 버림 | 그 봇의 설명 칸에 "하지 않음" 목록이 있는지 확인. 기본 봇에게 "하린(작가)의 설명과 지시문을 보여 줘"라고 해서 실제로 저장된 값을 확인 |
| 넘겼다는데 아무도 안 함 | 받은 봇의 대화방을 확인. 그래도 없으면 담당 봇에게 직접 시킴 |
| 저장된 지시문이 내가 준 것과 다름 | 기본 봇이 요약해서 저장했을 수 있음. "요약하지 말고 그대로 다시 저장해 줘"라고 요청 |
| 앱 화면이 이 문서와 다름 | 다른 점을 기록해 두고 이 문서를 고침 |
