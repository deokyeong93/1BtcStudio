# 스튜디오 스타일

직원 매뉴얼은 이 문서와 작법 파일을 근거로 합니다. 방향이 바뀌면 해당 파일을 먼저 고치고, 그다음 매뉴얼에 반영합니다.

- 대사: [dialogue-style.md](dialogue-style.md). 장면마다 `문법:` 비율을 적습니다. 하린의 0단계는 시리즈인지 새 이야기인지만 정하고 대본을 쓰지 않습니다.
- 화면: [direction-style.md](direction-style.md). 샷마다 `연출:`을 적습니다. 한 작품에 연출 하나를 잠그지 않습니다.
- 캐스팅·의상: [casting-style.md](casting-style.md). 작품마다 `캐스팅:` 비율, 인물마다 `계층:`. 주연을 예쁘거나 잘생긴 얼굴로 통일하지 않습니다. 실존 배우 얼굴은 재현하지 않습니다.
- 제목·편집: [post.md](post.md). 제목 100자 이내, 핵심은 앞 40자, 낚시성 과장 금지. 음악은 결정적인 순간에만. 본편은 조였다가 풀고, 예고편은 처음부터 빠르게.

작법 문서에 나온 사람은 방법의 출처입니다. 그 사람인 척하지 않고, 작품의 장면과 대사를 베끼지 않습니다.

## 포맷

| 항목 | 정한 것 |
|---|---|
| 기본 길이 | 2~3분 |
| 숏츠·예고편 | 요청할 때만 |
| 언어 | 한국어 우선 |
| 샷 | 약 5초, 동작 하나. 얼굴 고정은 주연만 |
| 대사 양 | 립싱크가 약하므로 짧게. 음성은 통과한 문장을 그대로 읽는다 |

## 누가 정하나

대표는 단계 안에 들어가지 않습니다. 고를 것은 담당 추천안을 채택합니다. 검수(대본, 프롬프트)는 승인 없이 생성 전에 합니다.

| 대표 승인이 필요한 것 | 방식 |
|---|---|
| 크레딧이 드는 생성 | 실행 전, 숫자 한도 |
| YouTube 공개 | 공개 전 승인. 공개 시점은 준호가 추천만 한다 |
