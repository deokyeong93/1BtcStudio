# 툴 사용 가이드북 (처음 쓰는 대표용)

4단계(소리·편집)와 5단계(배포)에서 대표가 직접 버튼을 누르는 툴 사용법입니다. Higgsfield는 [higgsfield-guide.md](higgsfield-guide.md)를 봅니다.
**무엇을 넣을지(프롬프트, 원고, 편집 메모)는 직원이 레포에 미리 써 두고, 대표는 복사해 넣고 결과를 저장·기록만 합니다.**

> - 확인 기준일: 2026-10-04. 툴 화면과 요금은 자주 바뀝니다. 메뉴 이름이 다르면 비슷한 이름을 찾고, 바뀐 점은 이 문서에 고쳐 적습니다.
> - 요금·상업 이용 조건은 이 문서의 숫자를 믿지 말고 **가입 직전에 공식 요금제 페이지에서 확인**한 뒤 [tools.md](tools.md)에 적습니다.
> - 비밀번호, 결제 정보는 어디에도 적지 않습니다.

---

## 0. 한눈에 보기

| 툴 | 무엇을 하나 | P001에서 쓰는 곳 | 크레딧(돈) | 준비하는 직원 |
|---|---|---|---|---|
| **Higgsfield** | 이미지·영상 생성, Soul ID(얼굴 고정) | 주인공 얼굴, 면접실, 샷 영상 약 16개 | 듦 → **대표 승인** | 서아(외모), 도윤(프롬프트) |
| **ElevenLabs** | AI 목소리, 효과음 | 상구 속마음 내레이션, 알림음·진동·의자 소리 | 듦(적음) | 하린(원고), 준호(효과음 목록) |
| **Suno** | AI 음악 | 씬 5 음악 1곡 (+ 씬 15 여부) | 듦(적음) | 준호 |
| **CapCut** | 편집, 자막, 그래픽 | 이어 붙이기, 채팅 화면, CCTV 타임스탬프, 슬로·프리즈, 색보정 | 무료로 충분할 가능성 높음 | 준호(편집 메모) |
| **YouTube** | 공개 | 업로드 | 무료 → 공개는 **대표 승인** | 준호(제목·설명) |

P001은 입 모양이 보이는 대사가 없어서 **립싱크(Lipsync Studio, sync.so)는 쓰지 않습니다.**

전체 제작 순서(기획 → 크레딧 계산 → 생성 → 소리·편집 → 공개)는 [higgsfield-guide.md](higgsfield-guide.md) 0장에 있습니다. 이 문서는 대표가 직접 만지는 툴(ElevenLabs, Suno, CapCut, YouTube) 사용법입니다.

## 1. 시작 전 준비 (한 번만)

### 1-1. 저장 폴더 만들기
영상·이미지·음원은 git에 올리지 않습니다([handbook 4장](handbook.md)). 구글 드라이브 같은 클라우드에 아래처럼 만듭니다.
```
1BtcStudio/
  P001-pilot/
    02-preproduction/   ← 캐릭터 이미지
    03-production/      ← 샷 영상
    04-post/            ← 음성·효과음·음악·편집 프로젝트
    05-distribution/    ← 최종본·썸네일
```
- 파일 이름은 반드시 규칙대로: `P001_shot_S03_v1.mp4`, `P001_char_sanggu_v1.png` ([handbook 3장](handbook.md))
- 폴더 링크는 작품 `README.md`의 "원본 미디어 링크" 표에 붙입니다.

### 1-2. 가입 순서
**한꺼번에 다 결제하지 말고, 쓸 단계가 오면 그때 가입합니다.** 구독은 매달 돈이 나갑니다.

| 순서 | 툴 | 언제 | 요금제 고르는 기준 |
|---|---|---|---|
| 1 | Higgsfield | 도윤의 예상 크레딧이 나온 뒤 | [higgsfield-guide.md](higgsfield-guide.md) 1장 |
| 2 | ElevenLabs | 샷 생성이 끝나 갈 때 | **상업 이용이 되는 가장 싼 유료 요금제**. 무료는 YouTube 수익 영상에 쓰면 안 됨 |
| 3 | Suno | ElevenLabs와 같은 때 | **유료 요금제에서 만든 곡만** 상업 이용 가능. 무료로 만든 곡은 쓰지 않음 |
| 4 | CapCut | 편집 시작할 때 | 무료로 시작. 막히는 기능이 있으면 그때 유료 검토 |

가입하면 바로 할 일:
1. [tools.md](tools.md) 표에 요금제·월 요금·가입 이메일·상업 이용 여부·확인일 적기
2. [budget.md](budget.md) "월 구독료"에 한 줄 추가
3. 상업 이용 약관 화면을 캡처해 클라우드 폴더에 보관하고 [licenses.md](licenses.md)에 기록

## 3. ElevenLabs: 내레이션·효과음 (4단계)

### 내레이션 (상구 속마음 목소리)
1. 준호가 쓴 원고 확인: `04-post/audio.md` (씬 번호별 문장, 쉬는 곳 표시)
2. elevenlabs.io → **Voices**(목소리) → **Voice Library**(공유 목소리)
   - 검색어는 [characters.md](../projects/P001-pilot/01-development/characters.md) 상구 항목의 "보이스 검색 키워드"를 씁니다: `Korean male, 40s, warm, soft, conversational, deadpan`
   - 언어 필터 **Korean**
   - 후보 2~3개를 같은 문장으로 들어 보고 하나를 **Add to my voices**(내 목소리에 추가)
   - 실존 유명인 목소리를 흉내 낸 보이스는 고르지 않습니다.
3. **Text to Speech**(글 → 음성) → 고른 목소리 → 한 씬 문장씩 붙여 넣고 생성
   - 한 번에 전체를 넣지 말고 **씬 단위**로 만듭니다. 고치기 쉽습니다.
   - "…"에서 쉬지 않으면 문장을 나눠 따로 만들고 편집에서 간격을 둡니다.
   - 설정(Stability 등)을 바꿨다면 값을 `audio.md`에 적어 다음 씬도 똑같이 맞춥니다.
4. 다운로드 → `P001_voice_S02-sanggu_v1.wav` (WAV가 있으면 WAV, 없으면 MP3)

### 효과음
- **Sound Effects**(효과음) 메뉴에서 영어로 짧게 설명하고 생성합니다. 예: `smartphone message notification sound, short`, `phone vibrating on a wooden desk`, `office chair pushed back quickly`
- 목록은 준호가 `audio.md`에 씁니다. 저장 이름은 `P001_sfx_notification_v1.wav`.
- 사무실 웅얼거림 같은 현장음도 여기서 만들 수 있습니다.

## 4. Suno: 음악 (4단계)

P001은 음악이 **씬 5에 처음 한 번**, 씬 15에는 준호가 판단해 넣거나 뺍니다. 곡 설명은 준호가 `04-post/music.md`에 씁니다.

1. suno.com → **Create**(만들기)
2. 가사 없는 곡이 필요하므로 **Instrumental**(연주곡)을 켭니다.
3. 스타일 칸에 준호가 쓴 설명을 붙여 넣습니다(예: 피아노 위주, 잔잔하게 시작, 실존 가수·밴드 이름은 쓰지 않음).
4. 생성하면 보통 2곡씩 나옵니다. 마음에 드는 것을 다운로드해 `P001_music_scene05_v1.mp3`로 저장합니다.
5. 곡 길이는 신경 쓰지 않아도 됩니다. 편집에서 필요한 부분만 자릅니다.
6. **유료 요금제에서 만든 곡인지** 확인하고 [licenses.md](licenses.md)에 기록합니다.

## 5. CapCut: 편집 (4단계)

PC용 CapCut(데스크톱 앱)을 권합니다. 휴대폰 앱보다 정밀하게 자를 수 있습니다. 무엇을 어디에 넣을지는 준호의 `04-post/edit-notes.md`를 따릅니다.

### 기본 화면
```
┌──────────────┬──────────────────┬─────────────┐
│ 미디어(불러온 │   미리보기 화면   │ 속성 창      │
│ 파일 목록)    │                  │ (크기·속도·색)│
├──────────────┴──────────────────┴─────────────┤
│ 타임라인: 위에서부터 글자 / 영상 / 소리 줄      │
└───────────────────────────────────────────────┘
```

### 순서
1. **새 프로젝트** → 화면 비율 16:9 → 프로젝트 이름 `P001_edit`
2. **불러오기(Import)**: 채택된 샷(approved), 내레이션, 효과음, 음악 파일을 모두 끌어다 놓기
3. **이어 붙이기**: 샷을 `shotlist.csv` 순서대로 타임라인에 놓고, 앞뒤 필요 없는 부분을 자릅니다(클립 끝을 끌거나 재생 막대 위치에서 `분할`).
4. **내레이션**: 소리 줄에 씬별 내레이션을 놓고 화면에 맞게 위치를 옮깁니다.
5. **채팅 화면** (씬 1, 12, 14, 15): 검은 배경 + **텍스트**로 말풍선을 만들고, 글자가 한 글자씩 나오게 할 때는 텍스트 **애니메이션 → 타자기** 효과를 씁니다. 씬 12의 "썼다 지우기"는 글자 길이가 다른 텍스트 조각을 이어 붙여 표현합니다. 세부 모양은 준호의 편집 메모를 따릅니다.
6. **CCTV 느낌**: 텍스트로 구석에 `2026-10-04 13:02:15` 같은 녹화 시각을 넣고(시각은 준호가 씬별로 정함), 필요하면 **효과 → 노이즈/필름 그레인** 효과를 약하게 덮습니다.
7. **씬 5 슬로**: 클립 선택 → 속성 창 **속도** → 느리게(예: 0.5배). 씬 5만 노이즈 효과를 빼서 선명해지게 합니다.
8. **씬 9 프리즈**: 멈출 지점에서 클립 우클릭 → **프리즈(정지 프레임)**.
9. **소리 맞추기(믹싱)**: 내레이션이 가장 잘 들리게, 음악·효과음은 그보다 작게. 클립마다 볼륨을 조절합니다.
10. **색보정**: 클립 선택 → **조정**에서 밝기·색온도를 맞춰 샷 사이 색이 튀지 않게 합니다. 씬 5를 따뜻하게 바꾸지 않습니다(회의 결론).
11. **자막**: **자막 → 자동 자막(한국어)** → 생성된 글자를 원고와 비교해 틀린 곳을 고칩니다. 자막 파일(.srt)로도 내보내 `04-post/subtitles/`에 넣습니다.
12. **내보내기(Export)**: 해상도 1080p, 프레임 30fps → `P001_edit_v1.mp4`. 최종 확정본은 `P001_final_v1.mp4`.

### 주의
- **CapCut 안에 들어 있는 음악·효과음·스티커는 쓰지 않습니다.** 일부는 상업 이용이 안 되어 YouTube에서 저작권 문제가 생길 수 있습니다. 소리는 ElevenLabs·Suno에서 만든 것만 씁니다.
- 편집 프로젝트는 자주 저장합니다. 편집본을 다시 내보낼 때마다 v2, v3으로 올립니다.
- 편집본을 보고 고칠 점은 준호에게: `/1btcstudio 준호 편집본 v1 피드백` + 대표가 본 것을 글로.

## 6. YouTube: 올리기 (5단계)

1. studio.youtube.com → **만들기 → 동영상 업로드** → `P001_final_v1.mp4`
2. 제목·설명·태그: 준호가 쓴 `05-distribution/youtube.md`에서 복사 (로그라인은 내부용이라 그대로 쓰지 않음)
3. 썸네일 업로드: `P001_thumb_v1.png`
4. **"변경되거나 합성된 콘텐츠" 질문**: 사실적인 AI 생성 영상이므로 **"예"**로 표시합니다. YouTube 정책상 표시해야 합니다.
5. 아동용 아님 선택, 자막(.srt) 업로드
6. 공개 상태는 **비공개 → 저장** 먼저. 휴대폰에서 끝까지 한 번 보고 저작권 경고가 없는지 확인합니다.
7. 이상이 없으면 대표가 **공개**로 바꿉니다. 공개 시점은 준호가 추천합니다.
8. 작품 `README.md`에 공개일·링크를 적고, 며칠 뒤 `retrospective.md`(회고)를 씁니다.
