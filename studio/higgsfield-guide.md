# 제작 가이드북: 주제 한 줄 → 영상 완성 (대표용)

다음 작품부터는 이 문서 순서대로만 하면 됩니다. 대표가 하는 일은 **명령 네 번, 결제 한 번, 결과 확인, 마무리 편집**입니다.
툴 화면 사용법(ElevenLabs·Suno·CapCut·YouTube)은 [tool-guide.md](tool-guide.md)를 봅니다.

> 확인 기준일: **2026-10-04** (Higgsfield MCP로 직접 조회·생성해 봄). 요금·단가는 자주 바뀌므로 스킬이 생성 전에 다시 조회합니다.
> 비밀번호·카드 정보는 어디에도 적지 않습니다.

## 1. 기획 (`기획 <주제>`, 크레딧 0)

```
/1btcstudio-1step 기획 회사 면접관이 사실 AI였다면, 3분
```
- 주제 한 줄이면 됩니다. 길이·분위기·화면 형식을 같이 적으면 회의 안건에 들어갑니다.
- 새 작품은 `projects/P00X-<slug>/`로 만들어지고 이후 명령의 기본 대상이 됩니다.
- 방향은 직원 회의로 정하고 회의록이 `meetings/`에 남습니다. 대표에게 묻지 않습니다.
- 외모 원칙: 남주·여주는 드라마 주연급 미남·미녀, 주변 인물은 깨끗한 호감형, 설정상 비호감 역할만 예외([art.md](agents/art.md)).
- 끝나면 `03-production/credit-estimate.md`와 함께 "다음 입력: /1btcstudio-1step 생성 ○○○"을 보고합니다.

**마음에 안 들면** 생성 전에 말로 고칩니다. 예: `은솔 외모를 더 차분하게 바꿔 줘`, `씬 3 빼 줘`. 사진을 보여 줘도 됩니다. 실존 인물 사진은 분위기만 참고하고 얼굴은 닮게 만들지 않습니다.

## 3. 결제와 연결 (처음 한 번)

1. higgsfield.ai → Pricing → **Plus, Monthly** 결제. (Claude Code에 "힉스필드 요금제 보여 줘"라고 하면 결제 링크가 나옵니다.)
2. Claude Code에서 `/mcp` → `higgsfield`가 **connected**인지 봅니다.
3. 아니면 "힉스필드 로그인해 줘" → 나온 주소를 브라우저에서 열고 로그인·허용 → 브라우저에 "연결할 수 없음"이 떠도 정상입니다. 주소창의 `http://localhost:…/callback?code=…`를 통째로 복사해 Claude Code에 붙여 넣습니다.
4. "힉스필드 잔액 알려 줘"로 확인합니다.
5. [tools.md](tools.md)와 [budget.md](budget.md) "월 구독료"에 한 줄씩 적게 합니다: "힉스필드 Plus 결제했어, 장부에 적어 줘".

새 컴퓨터에서 `/mcp`에 higgsfield가 아예 없으면 터미널에서 한 번 실행합니다.
```
! claude mcp add --transport http --scope project higgsfield https://mcp.higgsfield.ai/mcp
```

## 4. 생성 (`생성 <한도>`)

### 1차: 얼굴 + 테스트 샷 2개
```
/1btcstudio-1step 생성 120
```
1. 서아의 기준 얼굴 생성 → 서아 검수 → 통과한 얼굴로 **캐릭터 Element 등록**(이름 = 레포 id, 예: `eunsol`). Element는 사진 1장으로 바로 만들어지고 이미지·영상 모델 모두에서 같은 얼굴을 씁니다.
2. 방 이미지 → 테스트 샷의 첫 장면 이미지 → 테스트 샷 영상 2개 → 서아 검수.
3. 보고가 오면 **대표가 테스트 샷을 직접 재생해 봅니다.** 서아는 1초 간격 정지 화면만 보므로 움직임의 어색함은 대표 눈이 정확합니다.
   - 얼굴이 마음에 안 들면: `은솔 얼굴 다시, 더 성숙하게, 한도 5`
   - 실존 배우가 떠오르면: `은솔이 ○○ 닮았어, 다시` (서아는 대표가 본 참고 사진을 볼 수 없습니다)

### 2차: 나머지 전부
```
/1btcstudio-1step 생성 400
```
- 이미 approved된 샷과 등록된 캐릭터는 건너뜁니다.
- 멈추면 보고의 "다음 입력"을 그대로 다시 넣습니다.
- 멈추는 조건: 한도 도달, 잔액 부족, 오류 3번 연속, 로그인 만료, 같은 샷 3번 연속 redo(대안을 보고에 적음)

### 결과물 위치
| 무엇 | 어디 | git |
|---|---|---|
| 이미지·영상·음성 원본 | `projects/<작품>/media/` | 안 올라감 → 대표가 클라우드에 백업 |
| 프롬프트·시도 기록, 생성 일지 | `03-production/prompts/`, `generation-log.md` | 올라감 |
| 크레딧 합계 | `studio/budget.md` | 올라감 |
| 샷 상태 | `02-preproduction/shotlist.csv` | 올라감 |

## 5. 소리·가편집 (`/1btcstudio-1step` → `후반 <한도>`)

```
/1btcstudio-1step
```
준호가 내레이션 원고(`04-post/audio.md`), 편집 노트(`edit-notes.md`), 자막 원고, 제목·설명을 씁니다. 크레딧 0.

```
/1btcstudio-1step 후반 20
```
1. **목소리 고르기**: 준호가 Higgsfield 프리셋 목소리 중 캐릭터에 맞는 것을 고르고, 보고에 미리 듣기 링크를 적습니다. 바꾸고 싶으면 `상구 목소리 더 낮은 걸로, 후보 3개 들려줘`.
2. **내레이션 생성**: 씬 단위로 만들어 `media/`에 저장합니다.
3. **가편집본**: ffmpeg로 approved 샷을 편집 노트 순서대로 잇고 내레이션을 얹어 `media/P00X_edit_v1.mp4`를 만듭니다. 자막 파일(`.srt`)은 `04-post/subtitles/`에 저장합니다.
4. 채팅 화면·손글씨처럼 그래픽이 필요한 컷은 검은 화면 자리표시로 두고 목록을 보고합니다.

## 6. 대표가 직접 마무리

Higgsfield MCP로는 일반 음악·효과음을 만들 수 없어서 이 부분은 직접 합니다.
| 할 일 | 툴 | 방법 |
|---|---|---|
| 음악 | Suno | 준호의 `04-post/music.md` 설명을 붙여 넣어 생성 → `media/`에 저장 ([tool-guide 4장](tool-guide.md)) |
| 효과음 | ElevenLabs 웹 | `audio.md` 효과음 목록대로 ([tool-guide 3장](tool-guide.md)) |
| 마무리 편집 | CapCut | 가편집본 + 음악·효과음 + 채팅 그래픽 + 자막(.srt) → `P00X_final_v1.mp4` ([tool-guide 5장](tool-guide.md)) |
| 공개 | YouTube | 비공개 업로드 → 확인 → 공개. "AI 합성 콘텐츠" 표시 ([tool-guide 6장](tool-guide.md)) |

다 끝나면 "커밋해 줘", 그리고 며칠 뒤 `/1btcstudio 회고`.

## 8. 2026-10-04 체험에서 배운 것

- **Basic 요금제는 Kling 3.0 생성이 막힙니다**(단가 조회만 됨). 실제 제작은 Plus로 합니다.
- **얼굴을 넣은 장면 이미지는 `gpt_image_2_5`가 맞습니다.** `soul_2`에 얼굴 사진을 참고로 넣으면 증명사진 구도를 그대로 따라갑니다. 프롬프트 첫 줄에 "참고 이미지는 얼굴만, 구도는 따르지 말 것"을 적습니다.
- **프롬프트 끝에 "no ○○"를 길게 나열하면 금지한 것이 오히려 그려집니다.** 원하는 것을 긍정문으로 씁니다.
- **점·소품의 좌우는 자주 뒤집힙니다.** 콧등처럼 좌우가 없는 위치가 안전합니다.
- **영상은 첫 장면 이미지를 꼭 넣습니다.** 얼굴 참고만 넣으면 카메라 높이·방·소품이 바뀝니다.
- **소리가 필요 없는 샷은 소리를 끕니다.** Kling 3.0 pro 10초가 25에서 17.5로 줄어듭니다.
- 이미지는 장당 0.12~0.5라 아끼지 않아도 됩니다. 크레딧은 영상에서 나갑니다.

기록: [P001 generation-log.md](../projects/P001-pilot/03-production/generation-log.md)
